Icones — Lucide overrides + adds

    
fr--* sont remplacées 1-1 par leurs équivalents Lucide (mapping icons.overrides). Lucide est stroke-based, donc le rendu en mask-image donne une silhouette en lignes (pas en aplat plein comme les Remix DSFR).

    
Overrides

    
DSFR strippe le préfixe fr-- dans les noms de classe — le fichier fr--success-fill.svg donne la classe .fr-icon-success-fill.

    

      success
      warning
      error
      info
      accessibility
    

    
Adds (nouvelles classes utilitaires)

    

      .fr-icon-flame
      .fr-icon-leaf
      .fr-icon-ademe-pin (alias map-pin)
